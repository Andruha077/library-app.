# Library App

Навчальний Java-проєкт, реалізований із використанням трирівневої архітектури.

## Технології
- Java 21
- Maven
- Jakarta Servlet API
- Jetty 11
- H2 Database
- JDBC
- SLF4J / Logback
- JUnit 5
- ArchUnit

## Структура проєкту
- `core` — доменні моделі, інтерфейси репозиторіїв та бізнес-логіка.
- `persistence` — робота з базою даних H2 через JDBC.
- `web` — вебрівень, HTTP-запити та сервлети.

## Реалізовані можливості
- Отримання списку книг із пошуком, сортуванням і пагінацією.
- Отримання інформації про книгу.
- Створення та видалення коментарів.
- Перевірка вхідних даних.
- Видалення коментарів протягом 24 годин після створення.
- Обробка HTTP-помилок.
- Логування подій.
- Автоматичні архітектурні тести.

## Запуск проєкту

Зібрати всі модулі:

```bash
mvn clean package
```

Запустити вебмодуль через Maven:

```bash
mvn -pl web jetty:run
```

Після запуску застосунок доступний за адресою:

`http://localhost:8080`

## Тестування

Для запуску тестів усіх модулів:

```bash
mvn test
```

Проєкт містить модульні та архітектурні тести.
